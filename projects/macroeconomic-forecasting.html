Macroeconomic Price Forecasting & Scenario Optimization Platform

CEIC 글로벌 거시경제 지표와 내부 데이터를 통합한 15년 시계열 DB를 구축하고, SARIMA/HoltWinters/Prophet 앙상블 + SLSQP 기반 가격 최적화로 경험 기반 가격 협상을 데이터 기반으로 전환. 사내 AX Best Practice 수상.

Skills & Technologies

Python Prophet SARIMA HoltWinters Time Series Forecasting SciPy (SLSQP) Huber Regression Feature Engineering CEIC API Pandas

Overview

거시경제 지표를 자동 수집해 내부 데이터와 묶은 시계열 DB 위에서, 변수별로 가장 잘 맞는 예측 모델을 자동으로 고르고, 예측값을 제약 조건 최적화에 넣어 가격 시나리오를 제시하는 구조입니다.

Problem

가격 협상이 담당자의 경험에 의존해 진행되었고, 판단 근거가 되는 거시경제 지표를 매번 수작업으로 수집해야 해서 연간 약 250시간의 데이터 수집 공수가 발생했습니다.

Solution

시계열 DB 구축: 원유 가격, 사료 가격, 환율 등 거시경제 지표를 CEIC에서 수집해 내부 데이터와 통합한 15년 시계열 DB를 구축했습니다.

자동 모델 선택: SARIMA, HoltWinters, Prophet을 변수별로 자동 백테스팅(3/5/8년 윈도우)해 최적 모델을 선택합니다.

원유 가격 예측: Huber Regression + Prophet + YoY Extrapolation 앙상블과 지연/계절성/COVID 더미 변수를 활용한 특성 엔지니어링을 적용하고, Milk-Feed Price Ratio를 축산 농가 구매력 프록시로 도출했습니다.

시나리오 최적화: SLSQP 기반 최적화로 비용/마진/파트너 가격 등 다중 제약 하에서 최적 가격안을 제시합니다.
