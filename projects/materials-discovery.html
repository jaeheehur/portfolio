LG화학 AX기술개발팀 2026.01 ~ 2026.03

Target Compound Literature Screening Platform

신소재 발굴을 위한 문헌 인텔리전스 파이프라인. 특허 DB와 학술 논문에서 키워드 기반 크롤링 및 API 수집을 수행하고, LLM이 물성/합성 조건/실험 방법을 구조화 테이블로 추출합니다. 연구자가 자연어로 데이터베이스를 조회할 수 있는 Text2SQL 챗봇을 함께 제공합니다.

Skills & Technologies

Python BeautifulSoup Selenium LLM LangChain Text2SQL Data Extraction SQL Flask

Overview

LLM으로 확장한 검색 쿼리로 특허와 논문을 폭넓게 수집하고, 문헌에서 핵심 실험 정보를 추출해 구조화 DB로 적재한 뒤, 연구자가 자연어로 바로 조회할 수 있도록 Text2SQL 챗봇으로 연결하는 구조입니다.

01
검색 쿼리 확장
LLM이 키워드를 확장한 특허 검색 쿼리 생성
02
문헌 수집
특허 DB/학술 논문 크롤링 및 API 수집
03
LLM 구조화 추출
물성/합성 조건/열 안정성 지표 추출
04
구조화 DB 적재
추출 결과를 테이블로 정리해 적재
05
Text2SQL 챗봇
자연어 질의를 SQL로 변환해 조회

Problem

연구자가 신소재 후보를 탐색하려면 특허와 논문을 수동으로 검색하고 정리해야 해서 많은 시간이 들었습니다. 키워드 검색만으로는 표현이 다른 문헌을 놓치기 쉬웠고, 정리된 결과를 다시 조회하려면 SQL 지식이 필요했습니다. 회사 차원에서는 소재 개발 주기를 36개월에서 12개월 이내로 줄이는 것을 목표로 하고 있어, 문헌 탐색 단계부터 속도를 높일 필요가 있었습니다.

Solution

검색 커버리지 확대: LLM이 생성한 확장 특허 검색 쿼리를 활용해 키워드 기반 검색의 커버리지를 높였습니다.

구조화 추출: 수집된 문헌에서 물성, 합성 조건, 실험 방법, 열 안정성 지표 등 핵심 정보를 LLM으로 자동 추출하여 구조화된 DB로 적재합니다.

Text2SQL 챗봇: 결과 DB에 자연어로 질의할 수 있는 챗봇을 제공해 연구자가 SQL 없이도 "100도 이상 온도 범위에서 합성된 분자량 200 이상의 화합물"과 같은 쿼리를 직접 실행할 수 있도록 했습니다.

Key Achievements

  • 수동 문헌 탐색 시간 절감, R&D 워크플로우 가속화
  • LLM 챗봇으로 자연어 쿼리를 통한 유연한 DB 검색 기능 확대
