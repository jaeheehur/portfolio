CP Expense Post-Audit Monitoring System

의약품 공급업자 지출보고서 대국민 공개 의무화(2024년 12월 시행)에 대응해 정확한 품의/지출내역 데이터 관리를 위해 추진. 10% 미만 수작업 샘플링으로 진행하던 검토 프로세스를 Rule-based 로직으로 설계/구현하고 OCE 플랫폼 내에 배포하여 사후점검 커버리지 100%를 달성했습니다.

Skills & Technologies

Python Rule-based Detection Kakao Maps API Geodesic Analysis Plotly/Dash SQL DataLake Pipeline Pandas

Overview

DataLake에서 품의/지출 데이터를 받아 여러 Rule로 이상 패턴을 걸러내고, 위치 정합성까지 검증한 뒤 재점검 대상만 추려 OCE 플랫폼에서 확인할 수 있도록 구성했습니다.

01
데이터 수집
DataLake 파이프라인으로 품의/지출 내역 적재
02
Rule 기반 점검
품의유형/계정명 불일치, 상한가액 초과 검사
03
위치 정합성 검증
Kakao Maps API로 식음료 제공 장소와 병원 간 거리 계산
04
재점검 대상 추출
다중 조건 필터링으로 의심 건 선별
05
OCE 플랫폼 배포
엔터프라이즈 플랫폼에서 결과 모니터링

Problem

월 3천 건 이상의 데이터를 수작업으로 검토하는 과정에서 Human-error가 발생할 수 있었고, 10% 미만을 샘플링하는 방식으로는 전체 내역을 점검할 수 없어 지출보고서 공개 의무화에 따른 법적 리스크가 남아 있었습니다.

Solution

품의유형 및 계정명 불일치: 디테일 활동 약 4만여 건 중 일부 불일치 유형 검출

식음료 제공 장소와 병원 간 거리 점검: 디테일 활동을 위한 식음료 제공 장소와 디테일 대상의 소속 병원 거리가 조건 이내에 부합하는지 점검하여 약 10% 가량 재점검 필요 사례 검출

계정 상한가액 초과 탐지: 100% 스크리닝 달성

Key Achievements

  • 월 3,500건 이상 사후점검 커버리지를 10% 미만 샘플링에서 100%로 확대
  • DataLake 파이프라인 + LG CNS 협업을 통해 OCE 플랫폼 엔드투엔드 배포
  • 규제 공시 리스크 사전 탐지 체계 구축
