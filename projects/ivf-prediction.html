IVF Live Birth Outcome Prediction Model

HFEA(Human Fertilisation and Embryology Authority) 데이터셋을 활용해 IVF 시술의 생존 출생 결과를 예측하는 모델. 이 모델을 기반으로 LG AI Research와 협력해 LG Aimers 6회 해커톤(2,000+ 참가자, 27개 결선팀)을 출제했으며, FAME 2025에서 150+ 의사 참석자 대상으로 발표했습니다.

Skills & Technologies

Python Scikit-learn LightGBM Pandas Feature Engineering Clinical Data Analysis HFEA Dataset

Overview

HFEA 공개 데이터셋의 임상/실험실 특성으로 생존 출생 예측 모델을 만들고, 이를 해커톤 문제로 출제한 뒤 결선팀의 접근법을 다시 모델 개선에 반영하는 구조로 진행했습니다.

01
HFEA 데이터 수집
IVF 시술 공개 데이터셋 확보
02
특성 엔지니어링
시술 유형/배아 정보/환자 연령 등 특성 구성
03
예측 모델 개발
생존 출생 여부 분류 모델 학습
04
해커톤 출제
LG Aimers 6회 문제 출제 및 심사
05
모델 고도화/발표
결선팀 접근법 반영, FAME 2025 발표

Problem

IVF 시술의 생존 출생 결과는 시술 유형, 배아 정보, 환자 연령 등 여러 임상/실험실 요인이 함께 작용해 사전에 가늠하기 어렵습니다. 공개 데이터를 활용해 이 결과를 예측할 수 있는지 확인하고자 했습니다.

Solution

예측 모델: HFEA 공개 데이터셋의 임상/실험실 특성(시술 유형, 배아 정보, 환자 연령 등)을 기반으로 IVF 생존 출생 결과를 예측하는 분류 모델을 개발했습니다.

해커톤 출제: LG AI Research와 협력해 이 모델을 LG Aimers 6회 해커톤의 기반 문제로 출제했습니다.

모델 고도화: 결선 27팀의 특성 엔지니어링 접근법을 검토해 모델 개선에 반영하고, FAME 2025(Fertility Advancement Meeting) 학술회의에서 150명 이상의 의사를 대상으로 발표했습니다.

Key Achievements

  • LG Aimers 6회 해커톤 출제 및 심사위원으로 참여 (참가자 2,000+, 결선 27팀)
  • FAME 2025 학술회의 발표 (150+ 의사 참석자)
  • 해커톤 결선팀 접근법을 반영한 모델 고도화
