# Jaehee Hur / Portfolio

Senior Data Scientist portfolio site, served with GitHub Pages at https://jaeheehur.github.io/portfolio/.

## Structure
| Path | Content |
|---|---|
| `index.html` | Landing page: intro, impact stats, featured and selected projects, publications, talks and recognition |
| `projects.html` | All projects with a category filter (LLM/Agent, 품질/규제, 예측/최적화, 바이오/의료) |
| `career.html` | Career timeline, education, skills |
| `projects/*.html` | One page per project: overview flowchart, problem, solution, key achievements |
| `static/images/covers/` | Card cover image per project |
| `static/files/` | CV (PDF) |

Plain HTML and CSS, no build step. Editing rules (punctuation, page structure, facts kept consistent across pages) are in [`CLAUDE.md`](CLAUDE.md).
